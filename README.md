# Comet App 🚀

A Career Guidance Chatbot built with Flutter (Frontend) and Flask (Backend) to assist users in making informed career decisions through interactive responses.

## ✨ Features

Interactive Chatbot: Provides career advice based on user queries.

Smart Responses: Processes user input to provide relevant career guidance.

User Authentication: Secure login for personalized experience.

Real-Time Communication: Fast and responsive API calls between frontend and backend.

Bookmark & History: Save past conversations for future reference.


## 🛠 Tech Stack

Flutter (UI & Frontend)

Flask (Backend & API)

Firebase (Authentication)

## 🚀 Installation

Frontend (Flutter)

1. Clone the repository:

```sh
git clone https://github.com/your-username/comet-app.git
cd comet-app
```

2. Install dependencies:
```sh
flutter pub get
```

3. Run the app:
```sh
flutter run
```
